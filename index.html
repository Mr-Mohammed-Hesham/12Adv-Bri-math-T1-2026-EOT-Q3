نظرية الشطيرة (Squeeze Theorem)

If f(x) ≤ g(x) ≤ h(x)
and lim f(x) = lim h(x) = L
then lim g(x) = L
Key bounds:
-1 ≤ sin(θ) ≤ 1
-1 ≤ cos(θ) ≤ 1
0 ≤ sin²(θ) ≤ 1
0 ≤ cos²(θ) ≤ 1
